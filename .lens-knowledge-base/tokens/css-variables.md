# CSS Variables

## Usage Example

```css
.myClass {
  font-size: var(--lns-fontSize-medium);
  line-height: var(--lns-lineHeight-medium);
  box-shadow: var(--lns-shadow-medium);
  padding: var(--lns-space-large);
  color: var(--lns-color-primary);
}
```
