# 30.Loader

## Usage Guidelines

## Usage

```javascript
import { Loader } from '@loomhq/lens'
;<Loader />
```

---

## Sizes

```javascript
<Arrange gap="medium">
  <Loader size="small" />
  <Loader size="medium" />
  <Loader size="large" />
</Arrange>
```

---

## Color

Use one of the **palette colors**.

```javascript
<Loader color="orange" />
```

---

## Props

| Name  | Type                             | Default    |
| ----- | -------------------------------- | ---------- |
| color | string                           | `'body'`   |
| size  | `'small' \| 'medium' \| 'large'` | `'medium'` |
